# User

The person who owns the Mac and takes part in the calls.

## Events

### START_RECORDING
The user starts a recording by hand from the menu bar.

### ACCEPT_PROPOSAL
The user accepts the proposal to record the call that has just started.

### STOP_RECORDING
The user stops the recording in progress from the menu bar.

### CHOOSE_LANGUAGE
The user chooses the transcription language in the settings.

### OPEN_SETTINGS
The user opens the settings window.

### TURN_ON_REFINEMENT
The user turns on the refinement of transcripts in the settings.

### TURN_OFF_REFINEMENT
The user turns off the refinement of transcripts in the settings.

### OPEN_WINDOW
The user opens the archive window.

### CLOSE_WINDOW
The user closes the archive window.

### SELECT_CALL
The user selects a call in the archive.

### EXPORT_CALL
The user exports the transcript of the selected call.

### RENAME_CALL
The user gives a call a title of their own.

### RENAME_PARTICIPANT
The user gives a participant of a call a name of their own.

### REFINE_TRANSCRIPT
The user asks to refine the transcript of the selected call.

### RESTORE_TRANSCRIPT
The user brings the transcript of the selected call back to its original text and speakers.

### DELETE_CALL
The user deletes a call after confirming.

### PLAY
The user starts or resumes listening to the audio of the selected call.

### PAUSE
The user pauses the audio of the selected call.

### SELECT_SENTENCE
The user clicks a sentence of the transcript of the selected call.
