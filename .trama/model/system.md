# LARP

A macOS app for Apple silicon Macs that records the user's calls and transcribes them on the Mac, without sending audio anywhere. It lives in the menu bar, offers to record when a call app starts using the microphone, transcribes the user's voice and the other participants in Italian or English, then tells the participants apart. When the user turns it on, the text of the transcript, never the audio, is refined by an AI assistant installed on the Mac. When the user turns it on, the same assistant also writes a summary of each call from the text of its transcript, never the audio: the key concepts, the decisions taken and the next steps, because the app is meant above all to keep what was decided rather than every word. A window keeps the archive of recorded calls, to search, read, listen to, rename, export and delete them.
