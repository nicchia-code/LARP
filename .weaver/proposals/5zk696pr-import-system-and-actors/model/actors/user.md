# User

The person who owns the Mac, takes part in the calls and uses the menu bar, the archive window and the settings window.

## Events

### START_RECORDING
The user chooses "Registra" in the menu bar while no proposal to record is shown, to record by hand without a call app.

### ACCEPT_PROPOSAL
The user accepts the proposal to record a call that has just started, with "Registra" in the proposal or in the menu bar while the proposal is shown.

### STOP_RECORDING
The user chooses "Ferma registrazione" in the menu bar.

### OPEN_WINDOW
The user opens the archive window from the menu bar.

### CLOSE_WINDOW
The user closes the archive window.

### SELECT_CALL
The user selects a call in the list of the archive window.

### DESELECT_CALL
The user clears the selection of the list of the archive window.

### SHOW_SUMMARY
The user switches the selected call to its summary.

### SHOW_TRANSCRIPT
The user switches the selected call to its transcript.

### RENAME_CALL
The user gives a call a title of their own, or clears it to get the default title back.

### RENAME_PARTICIPANT
The user gives a participant of a call a name of their own, or clears it to get the default name back.

### ASK_TO_DELETE
The user asks to delete the selected call; the app asks for confirmation.

### CANCEL_DELETION
The user cancels the deletion of a call when asked for confirmation.

### DELETE_CALL
The user confirms the deletion of a call.

### EXPORT_CALL
The user exports the selected call as a Markdown file.

### REFINE_TRANSCRIPT
The user asks to refine the transcript of the selected call.

### RESTORE_TRANSCRIPT
The user brings the transcript of the selected call back to the text and speakers it had before refinement.

### SUMMARIZE_CALL
The user asks omp to write the summary of the selected call, or to write it again.

### PLAY
The user starts or resumes listening to the audio of the selected call.

### PAUSE
The user pauses the audio of the selected call.

### SEEK
The user moves the playback position of the selected call to another time.

### SELECT_SENTENCE
The user clicks a line of the transcript of the selected call.

### OPEN_SETTINGS
The user opens the settings window.

### CHOOSE_LANGUAGE
The user chooses the transcription language, Italian or English, in the settings.

### TURN_ON_REFINEMENT
The user turns on the refinement of transcripts in the settings.

### TURN_OFF_REFINEMENT
The user turns off the refinement of transcripts in the settings.

### TURN_ON_SUMMARY
The user turns on the summaries of calls in the settings.

### TURN_OFF_SUMMARY
The user turns off the summaries of calls in the settings.

### TURN_ON_LAUNCH_AT_LOGIN
The user turns on starting the app at login in the settings.

### TURN_OFF_LAUNCH_AT_LOGIN
The user turns off starting the app at login in the settings.
